Setup

Running in under 2 minutes

Python 3.11+ required. Or use Docker — no Python install needed.

1

Clone & install

git clone https://github.com/annointedfrom/terminal-monitor then pip install -r requirements.txt

2

First-run setup

Run python setup.py to generate your config.yaml. Add your services, alert thresholds, and license key.

3

Start the dashboard

uvicorn termmon.main:app --port 8084 — then open localhost:8084 in your browser.

4

Or use Docker

docker-compose up — mounts your config and data directory, handles everything else. Works on Mac, Windows, and Linux.
