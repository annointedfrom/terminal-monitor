★ TRAINING MODE

RUNNING IN UNDER 2 MIN

Python 3.11+ required. Or use Docker — no Python install needed.

A COMMAND 01

CLONE & INSTALL

git clone …/terminal-monitor then pip install -r requirements.txt. Standard Python flow.

B COMMAND 02

FIRST-RUN SETUP

Run python setup.py to generate config.yaml. Drop in your services, alert thresholds, and license key.

X COMMAND 03

START THE DASH

uvicorn termmon.main:app --port 8084, then open localhost:8084. You're in.

Y COMMAND 04

OR USE DOCKER

docker-compose up mounts config + data dir and handles the rest. Mac, Windows, Linux.
